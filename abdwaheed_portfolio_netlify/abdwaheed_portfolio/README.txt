ABDWAHEED YUSUFF-BALOGUN — PORTFOLIO WEBSITE

Files:
- index.html: portfolio content
- styles.css: responsive visual design
- script.js: mobile navigation and current year
- cv.txt: source CV text for reference

Deploy:
1. Extract this ZIP on your computer.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder (the folder containing index.html) into the Netlify Drop area.
4. Netlify will publish a preview URL ending in netlify.app.

Before public job applications:
- Verify the live QuizNova/PartyPulse URL and add it to the project card.
- Add a downloadable PDF CV after checking the final CV file.
- Confirm certification names and dates match the certificates exactly.
- The finance workflow demo is explicitly illustrative and uses no real customer data.
